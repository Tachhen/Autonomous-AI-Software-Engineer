 Autonomous AI Software Engineer

An LLM-powered autonomous coding agent that can inspect a software repository, understand code, modify source files, run tests, and iteratively solve software-engineering tasks.

Overview

**Autonomous AI Software Engineer** is an experimental AI coding agent built with Python and LLM tool calling.

The goal of the project is to move beyond simple code generation and build an agent that can actually interact with a software repository.

Given a task such as:

"Fix the failing tests in this repository"
the agent can:
1.Inspect the repository
2.Read relevant source files
3.Search the codebase using semantic retrieval
4.Identify the source of a problem
5.Modify source code
6.Run the test suite
7.Analyze test results
8.Iterate until the task is resolved
9.Store information about the execution in agent memory
